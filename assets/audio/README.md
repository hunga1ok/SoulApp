# Soul audio delivery folder

This folder contains the bundled MVP audio package. The accompanying
`assets/content/audio_manifest.json` is the approved selection map from
`Soul_Owned_Content_Audio_Manifest_Mapping_v2.0.md`.

The current package contains 60-second synthesized ambience/music beds and
separate Vietnamese and English guided tracks. The nine Vision guided tracks
are rendered from the complete corresponding sections of
`Specs/Soul_Full_Audio_Scripts_VI_EN_Production_v2.1.md`, not from summaries.
Each file has the exact `assetPath` declared in the manifest. Replacing an
asset with its mastered production version keeps the same path and mapping.

- Guided narration must have separate `vi-VN` and `en` files. Never substitute
  one language for the other.
- Music and ambience are language-neutral.
- Files are AAC/M4A at 96 kbps for the MVP bundle.
- Do not add files from YouTube, Spotify or an unlicensed source. Confirm the
  distribution terms for any replacement voice or music file before release.
